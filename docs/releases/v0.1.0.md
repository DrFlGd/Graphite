First release of Graphite: milestones **M0 (foundations)** and **M1 (capture and connect)** of the [roadmap](https://github.com/DrFlGd/Graphite/blob/main/ROADMAP.md).

## What you get

- **A vault is a folder.** Notes are Markdown files with YAML front matter, attachments sit beside them, and the only thing Graphite adds is a rebuildable index in `.graphite/`. Open any folder from the welcome screen; `fixtures/sample-vault` in the repo is a small one to try.
- **Editor.** Rich Markdown editing with an insert toolbar and a `/` menu for headings, lists, tasks, quotes, code, tables, images and embeds; a Markdown-source toggle; `[[` to link notes with autocomplete. Everything round-trips to plain Markdown.
- **Capture.** `Ctrl/Cmd+Shift+Space` anywhere (even with the app in the background) opens a quick-capture box that saves to the Inbox; the Inbox view files captures into folders. `Ctrl/Cmd+D` opens today's daily note.
- **Connect.** Backlinks and unlinked mentions beside every note, a graph of the whole vault or the neighbourhood of a note (typed links dashed, missing notes hollow), and a command palette on `Ctrl/Cmd+Shift+P`.
- **Workspace.** Tabs, up to three split panes, full-text search, drop or paste files into notes to attach them.
- **CLI.** `graphite list | search | capture | daily | graph` over the same vault.

## Install

Pick the file for your platform below. The builds are not code-signed yet, so the first launch needs one extra step:

- **macOS** (`Graphite_0.1.0_universal.dmg`): drag to Applications, then run `xattr -cr /Applications/Graphite.app` once, or right-click the app and choose Open.
- **Windows** (`Graphite_0.1.0_x64-setup.exe` or the `.msi`): in the SmartScreen prompt choose "More info", then "Run anyway".
- **Linux**: `.AppImage` (make it executable), `.deb` or `.rpm`.

The `graphite-cli-*` archives contain the command-line tool.

## Known limits

Single device, no sync yet (that is M3). Projects, tasks and progress tracking (M2) come next.
