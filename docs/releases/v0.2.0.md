Milestone **M2 (projects and progress)** of the [roadmap](https://github.com/DrFlGd/Graphite/blob/main/ROADMAP.md): notes become projects with tasks, open questions and a hub page, and a query language drives list, table, board and tree views.

## What is new

- **Tasks anywhere.** A `- [ ]` line in any note is a task; `- [/]` in progress, `- [x]` done, `- [-]` cancelled. Add `due:: 2026-11-01`, `priority:: p1` (or `#p1`) and `project:: [[Name]]` on the line. Tasks nest by indentation. In the editor the checkbox toggles done, right-click or `Ctrl/Cmd+Enter` cycles the state.
- **Open questions.** `- [?] What current does the pump draw?` is a gap: something to find out. Type `/open question` in the editor to add one. A gap is resolved by recording which note answers it; the `?` box in any view does that.
- **Projects.** A note with `type: project` opens as its hub: progress bar, its tasks (gathered from every note that names it), open questions, decisions, sources and linked notes. "Edit note" shows the text.
- **Templates.** New note from template (`Ctrl/Cmd+Shift+N`): project, research, build, software, writing, decision, query, plus any `templates/*.md` in your vault. "Promote to a project" in the palette turns an idea into a project in place.
- **Tasks view** (`Ctrl/Cmd+Shift+T`): every task or question in the vault, filtered by project and state, as a list, a table with inline editing, a board grouped by any field, or a nested tree.
- **Queries.** Type a query such as `type:task project:[[Garden Robot]] status:open sort:due group:priority` into any view, or save it as a `type: query` note that opens as its results. The language is documented in `docs/spec/vault-format.md`.
- **Properties.** Front matter is editable in the side panel: type, aliases, any property.
- **CLI.** `graphite tasks | gaps | done | answer | add | field | progress | query | templates | promote | hub`, and `new --template`.

## Install

Pick the file for your platform below. The builds are not code-signed yet, so the first launch needs one extra step:

- **Windows** (`Graphite_0.2.0_x64-setup.exe` or the `.msi`): in the SmartScreen prompt choose "More info", then "Run anyway".
- **Linux**: `.AppImage` (make it executable), `.deb` or `.rpm`.

There is no macOS build in this release. The `graphite-cli-*` archives contain the command-line tool.
