Importers that work on a fresh computer.

## Fixed

- **The app no longer freezes while importing.** Downloading a repository, page or video used to lock the whole window until it finished, which on Windows showed as "Not responding". Imports and update checks now run in the background, and the rest of the app keeps working.
- **GitHub repositories import without git.** When git is not installed, Graphite downloads the repository as an archive from GitHub. Other hosts (GitLab, Codeberg, plain git URLs) still need git.
- **Imported repositories no longer flood the note list.** A repository's README, LICENSE and other files stay in its `repo/` folder and are not added as notes or listed under Files. Graphite also stops writing note ids into those files. Files from repositories imported earlier leave the note list the next time the vault opens.
- **Video imports can fetch yt-dlp for you.** When yt-dlp is missing, the import window offers "Download yt-dlp". It downloads the official build (about 40 MB) and checks it against the published checksum. Without ffmpeg, videos download as a single file, which on YouTube is usually lower quality. The command line has the same option: `graphite tools --install-yt-dlp`.
- **Page screenshots are more reliable.** The browser used for screenshots gets a profile of its own, so an open Chrome or Edge window no longer swallows the request. A browser that hangs is stopped after 45 seconds, and on Windows no console windows flash up during an import.

## Install

Pick the file for your platform below. The builds are not code-signed yet, so the first launch needs one extra step:

- **Windows** (`Graphite_0.3.4_x64-setup.exe` or the `.msi`): in the SmartScreen prompt choose "More info", then "Run anyway".
- **Linux**: `.AppImage` (make it executable), `.deb` or `.rpm`.
- **Android** (`graphite-v0.3.4-android-arm64.apk`): each release is signed with a fresh key, so the previous version must be uninstalled first. Uninstalling erases the notes stored in the app, so sync them to a relay before you do.
- **Relay** (`graphite-relay-v0.3.4-linux-x86_64.tar.gz`): run it on a machine both devices can reach, ideally behind HTTPS.

There is no macOS build in this release. The `graphite-cli-*` archives contain the command-line tool.

## Known limits

Video import is desktop only; the phone app has no importers yet. Otherwise as in 0.3.2.
