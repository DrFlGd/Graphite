A small release for the phone.

## Fixed

- **Android: adding files works.** "Add files" in a project, and inserting an image or file while editing, failed with a `content://…` error. The phone now uses the system file picker and copies the chosen files into the vault. Android grants access to just the files you pick, so the app still asks for no storage permission.
- **A new project's first file** shows in its Files list straight away instead of after reopening the project (desktop and phone).
- **Long error messages** wrap instead of running off the screen.

## Improved

- **Phone: a + button** in the top bar creates an empty note, a project, or a note from any template. A new note opens ready for typing.

## Install

Pick the file for your platform below. The builds are not code-signed yet, so the first launch needs one extra step:

- **Windows** (`Graphite_0.3.2_x64-setup.exe` or the `.msi`): in the SmartScreen prompt choose "More info", then "Run anyway".
- **Linux**: `.AppImage` (make it executable), `.deb` or `.rpm`.
- **Android** (`graphite-v0.3.2-android-arm64.apk`): open it on the phone and allow installing from that app. Each release is signed with a fresh key, so uninstall the previous version before installing a new one. Your notes live inside the app, so sync them to a relay first if the phone has notes no other device has.
- **Relay** (`graphite-relay-v0.3.2-linux-x86_64.tar.gz`): run it on a machine both devices can reach, ideally behind HTTPS.

There is no macOS build in this release. The `graphite-cli-*` archives contain the command-line tool.

## Known limits

As in 0.3.1. On the phone, a note cannot yet be turned into a project, and files cannot be opened from a project's Files list.
