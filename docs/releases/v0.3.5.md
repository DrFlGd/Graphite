Video imports that work with YouTube.

## Fixed

- **Video imports no longer fail with "Requested format is not available".** Graphite now asks yt-dlp which formats a video has, then downloads one of those. It picks the best picture up to 1080p with sound. Without ffmpeg it picks a file that already has both.
- **"Download video tools" gets everything YouTube needs.** YouTube hides most formats unless yt-dlp can run a JavaScript runtime (Deno). The button in the import window downloads Deno along with yt-dlp, and on Windows it also downloads ffmpeg for full quality. Each download is checked against its project's published checksum. After a failed video import the button offers "Update yt-dlp", because a newer yt-dlp usually fixes errors after a site changes. On the command line, run `graphite tools --install-video-tools`.
- **A failed import leaves nothing behind.** The source note is only created once the download succeeded, so it no longer appears in the note list while an import runs and stays there after it fails.
- **Notes deleted outside Graphite leave the list straight away.** Before, they stayed listed until something else changed.

## Install

Pick the file for your platform below. The builds are not code-signed yet, so the first launch needs one extra step:

- **Windows** (`Graphite_0.3.5_x64-setup.exe` or the `.msi`): in the SmartScreen prompt choose "More info", then "Run anyway".
- **Linux**: `.AppImage` (make it executable), `.deb` or `.rpm`.
- **Android** (`graphite-v0.3.5-android-arm64.apk`): each release is signed with a fresh key, so the previous version must be uninstalled first. Uninstalling erases the notes stored in the app, so sync them to a relay before you do.
- **Relay** (`graphite-relay-v0.3.5-linux-x86_64.tar.gz`): run it on a machine both devices can reach, ideally behind HTTPS.

There is no macOS build in this release. The `graphite-cli-*` archives contain the command-line tool.

## Known limits

On Linux, install ffmpeg with your package manager; the button does not download it there. Video import is desktop only. Otherwise as in 0.3.4.
