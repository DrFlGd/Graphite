Layout and colour polish.

## Improved

- **Notes read as a page.** The writing area is a centred sheet with visible edges. The title, tags and toolbar line up with the text instead of sitting at the far left. On a narrow pane the page fills the width.
- **Each note type has a colour and an icon:** project, idea, daily, capture, source, reading, decision, meeting, query and more. The colour appears on the type label in the sidebar and in the note's header. It also appears on the tab icon, on search results, in the side panel's backlinks, on the template picker, and in the graph. The Inbox, Today, Tasks and Sources buttons use the matching colour. On the phone, note lists show the type icon.
- **Daily notes keep their date.** Renaming a daily note to "Garden day" saves it as "Garden day (2026-10-14)". The Today button still finds it, and a daily note changed to another type (in the side panel's properties) can be titled freely.

## Install

Pick the file for your platform below. The builds are not code-signed yet, so the first launch needs one extra step:

- **Windows** (`Graphite_0.3.3_x64-setup.exe` or the `.msi`): in the SmartScreen prompt choose "More info", then "Run anyway".
- **Linux**: `.AppImage` (make it executable), `.deb` or `.rpm`.
- **Android** (`graphite-v0.3.3-android-arm64.apk`): each release is signed with a fresh key, so the previous version must be uninstalled first. Uninstalling erases the notes stored in the app, so sync them to a relay before you do.
- **Relay** (`graphite-relay-v0.3.3-linux-x86_64.tar.gz`): run it on a machine both devices can reach, ideally behind HTTPS.

There is no macOS build in this release. The `graphite-cli-*` archives contain the command-line tool.
