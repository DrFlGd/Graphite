Milestones **M3 (media and importers)** and **M4 (sync and mobile)** of the [roadmap](https://github.com/DrFlGd/Graphite/blob/main/ROADMAP.md): files of any kind live in the vault with previews, outside content is pulled in by importers, the same vault runs on several devices and a phone, and nothing is lost to a bad edit.

## What is new

### Media and importers (M3)

- **Files.** Any file dropped or pasted into a note or the `attachments/` folder is an asset: images, video, audio, PDFs, 3D models, code and data. The Files view lists them with thumbnails (video frames and PDF pages via ffmpeg and pdftoppm when installed); a file opens in its own tab with a viewer, a 3D model spins in the browser, and PDF text is searchable alongside notes.
- **Importers.** "Import from URL" (`Ctrl/Cmd+Shift+I`) takes a GitHub repository, a web page, a video link, a PDF or any file and makes a source note with the content: a repository's README, a page's readable text with an archived copy and a screenshot, a video and its thumbnail (yt-dlp), the PDF. Sources remember where they came from, can check for updates and re-import, and a project's hub lists its sources. A link captured to the inbox imports with one click.

### Sync (M4)

- **Shared folder.** Put a vault in Dropbox, Syncthing, OneDrive or on a USB stick and open it on another machine: edits merge without conflict dialogs, even when both machines change the same note while offline. Press Sync in the sidebar (or just open the folder) to turn it on.
- **Relay.** For devices without a shared folder, a small server you host ([`graphite-relay`](https://github.com/DrFlGd/Graphite/tree/main/apps/relay), one binary or a Docker image) moves changes between devices within a second or two. Everything is encrypted before it leaves a device; the relay stores only ciphertext. Open the sync panel (gear next to Sync), enter the relay's URL, and paste the invite on the other devices.
- **History.** Every note keeps its saved versions, from every device: open a note's history, see what changed line by line, and restore any version. A zip snapshot of the whole vault is taken once a day and kept in `.graphite/snapshots/` (or a folder you choose).
- **Large files.** Files over 100 MB (set in the sync panel) are linked where they are instead of copied in, and stay on their device.

### Android app (M4)

- Share text, a link, an image or a file from any app to Graphite and it lands in the inbox. The app has the inbox with a capture box, notes with search, tasks to tick off, and projects as their hubs; notes open for reading with images and can be edited. The vault lives in the app's storage and syncs through a relay.

### CLI

- `graphite import | sources | check | reimport | sync | device | relay | config | history | restore | snapshot`.

## Install

Pick the file for your platform below. The builds are not code-signed yet, so the first launch needs one extra step:

- **Windows** (`Graphite_0.3.0_x64-setup.exe` or the `.msi`): in the SmartScreen prompt choose "More info", then "Run anyway".
- **Linux**: `.AppImage` (make it executable), `.deb` or `.rpm`.
- **Android** (`graphite-v0.3.0-android-arm64.apk`): open it on the phone and allow installing from that app. Each release is signed with a fresh key, so uninstall the previous version before installing a new one.
- **Relay** (`graphite-relay-v0.3.0-linux-x86_64.tar.gz`): run it on a machine both devices can reach, ideally behind HTTPS.

There is no macOS build in this release. The `graphite-cli-*` archives contain the command-line tool.

## Known limits

Video quality choice, chapters and PDF metadata lookup, DXF/AI and STEP conversion, duplicate-file warnings and the website mirror importer are not in yet. On the phone there is no voice capture, home-screen widget or reminders. Conflicting edits to the same attachment (not notes) keep both copies rather than merging. The Android app does not yet pair by QR code; paste the invite instead.
