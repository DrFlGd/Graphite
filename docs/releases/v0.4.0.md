Features borrowed from Alexandrie and Obsidian: richer Markdown, links into headings and paragraphs, a few ways to find notes again, drawings, dictation and searchable scanned PDFs. Everything is written in the syntax Obsidian and GitHub already read, so notes stay plain Markdown.

## What is new

### Writing

- **Callouts.** `> [!tip] Title` boxes, foldable with `[!tip]+` or `[!tip]-`. The type, title and folding are set in the callout's header.
- **Maths.** Inline `$…$` and `$$` blocks, drawn with KaTeX. Click a formula to edit its LaTeX. Prices such as `$5 and $10` stay text.
- **Mermaid diagrams.** A ```` ```mermaid ```` code block shows its diagram, with the code underneath while the cursor is in it.
- **Footnotes and highlights.** `[^1]` footnotes, with the definition added after the last one, and `==highlighted text==` (toolbar button or `Ctrl+Shift+H`).
- **Snippets.** Notes with `type: snippet` or in a `snippets/` folder show up in the `/` menu and the toolbar's Insert menu. Inserting one fills in `{{title}}`, `{{date}}`, `{{time}}` and `{{datetime}}`. "Save the selection as a snippet" is in the command palette.
- **Drawings.** The Drawing block starts an Excalidraw drawing, saved as a `.excalidraw` file under `attachments/drawings/` and shown in the note as a picture. Click it to keep drawing; it saves by itself. Words in a drawing are searchable. Drawings work offline.
- **Dictation.** The Dictate button next to undo and redo records the microphone; press it again to write the words in at the cursor (Escape throws the recording away). Speech is recognised on your computer and nothing is sent anywhere. The first time, Graphite asks before downloading the 142 MB speech model. English only, on the desktop app.

### Links and finding things

- **Links to headings and paragraphs.** `[[Note#Heading]]` and `[[Note#^id]]` open the note at that heading or paragraph. "Copy link to this heading or paragraph" in the command palette makes one for you.
- **Embeds.** `![[Note]]`, `![[Note#Heading]]` and `![[Note#^id]]` show the note, the section or the paragraph in place, read-only.
- **Hover previews.** Hovering a note link shows a preview of the note.
- **Outline.** The side panel lists the open note's headings; click one to go there.
- **Bookmarks.** The star in the note header pins a note to the top of the sidebar (and of the phone's list).
- **Tag pane.** The sidebar switches between Notes and Tags. Tags nest on `/` (`project/robot`) and show their counts. `#tags` written in the text count now, not just those in the front matter.
- **Note icons and colours.** Pick an emoji or icon and a colour left of the title; they show in the sidebar, tabs and search.

### Files

- **Scanned PDFs are searchable.** A PDF with no text layer is read with Tesseract once, so its words turn up in search. It needs Tesseract and poppler (which PDF previews already use): on Windows the [Tesseract installer](https://github.com/UB-Mannheim/tesseract/wiki), on Linux `tesseract-ocr` and `poppler-utils` from your distribution. The PDF view tells you when a PDF looks scanned and Tesseract is missing.

### Plan

- Whiteboards (milestone M5) will be saved as [JSON Canvas](https://jsoncanvas.org) files, the format Obsidian uses, so they open in other apps too. The format is in the vault spec; the whiteboard itself is not built yet.

## Upgrading

The first time a vault is opened, Graphite rebuilds its search index and reads every file again so that scanned PDFs and drawings get their text. On a large vault with many PDFs this can take a few minutes. Your notes are not changed.

## Install

Pick the file for your platform below. The builds are not code-signed yet, so the first launch needs one extra step:

- **Windows** (`Graphite_0.4.0_x64-setup.exe` or the `.msi`): in the SmartScreen prompt choose "More info", then "Run anyway".
- **Linux**: `.AppImage` (make it executable), `.deb` or `.rpm`.
- **Android** (`graphite-v0.4.0-android-arm64.apk`): each release is signed with a fresh key, so the previous version must be uninstalled first. Uninstalling erases the notes stored in the app, so sync them to a relay before you do.
- **Relay** (`graphite-relay-v0.4.0-linux-x86_64.tar.gz`): run it on a machine both devices can reach, ideally behind HTTPS.

There is no macOS build in this release. The `graphite-cli-*` archives contain the command-line tool.

## Known limits

Dictation is English only and not in the phone app (use the keyboard's microphone there). OCR reads PDFs only, not images, and at most 200 pages of each. Drawings can be viewed on the phone but not edited. Exporting a note or project is not in yet. Otherwise as in 0.3.6.
