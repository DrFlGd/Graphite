Imports run in the background.

## Changed

- **Imports no longer block the window.** Pressing Import closes the import window straight away and the download carries on in the background. You can keep writing, searching or start more imports while it runs.
- **Progress shows in a panel in the bottom-right corner.** Each import shows what it is doing ("Reading the video's formats", "Downloading the video", "Cloning the repository") with a progress bar, and the size where it is known. The panel folds down to one line.
- **Any import can be cancelled.** Cancelling stops the download, including yt-dlp and git, and leaves no note or folder behind.
- **Failed imports stay in the panel with their error.** Retry runs the same import again. For a video, "Update yt-dlp and retry" downloads the newest yt-dlp first. Finished imports have an Open button and leave the panel by themselves after a few seconds.
- **The video tools download in the background too.** When they are missing, the import downloads them first as part of the same job.

## Fixed

- **Large files are no longer cut off after a minute.** Downloads used to stop after 60 seconds in total, which broke big files on slow connections. Now only reaching the server times out.

## Install

Pick the file for your platform below. The builds are not code-signed yet, so the first launch needs one extra step:

- **Windows** (`Graphite_0.3.6_x64-setup.exe` or the `.msi`): in the SmartScreen prompt choose "More info", then "Run anyway".
- **Linux**: `.AppImage` (make it executable), `.deb` or `.rpm`.
- **Android** (`graphite-v0.3.6-android-arm64.apk`): each release is signed with a fresh key, so the previous version must be uninstalled first. Uninstalling erases the notes stored in the app, so sync them to a relay before you do.
- **Relay** (`graphite-relay-v0.3.6-linux-x86_64.tar.gz`): run it on a machine both devices can reach, ideally behind HTTPS.

There is no macOS build in this release. The `graphite-cli-*` archives contain the command-line tool.

## Known limits

Closing Graphite cancels imports that are still running, so start them again after you reopen it. Otherwise as in 0.3.5.
