# 04 · Open questions

Decisions that shape the plan. Each had a recommendation; Jerred answered all of them on 2026-10-14 (recorded in the Decision column) and the load-bearing ones are written up as ADRs in `docs/decisions/`.

| # | Question | Options | Recommendation | Decision |
| --- | --- | --- | --- | --- |
| Q1 | **Stack** | A. Tauri 2 + Rust core + TS/React UI · B. Electron + React Native · C. Flutter + Rust FFI · D. Native per platform | **A.** One core across every platform, small binaries, strongest CRDT/SQLite/file-watch story in Rust, richest UI component ecosystem (editor, graph, canvas, 3D) in web tech. | **A, accepted** (ADR-001) |
| Q2 | **Vault storage** | A. Plain Markdown files + rebuildable index · B. Database-only (SQLite as source of truth) · C. Hybrid with files exported on demand | **A.** Interoperability with specialised tools and other note apps, trivial backup, no lock-in. Cost: a reconciler between disk, CRDT and index, which is the hardest piece of core. | **A, accepted**: content must stay human-readable if the software fails (ADR-002) |
| Q3 | **CRDT library** | Automerge (Rust-native) · Yjs (JS-native) · Loro (newer, Rust, fast) | **Automerge** if Q1 = A (Rust core). Revisit Loro at M4 if its ecosystem has matured. | **Automerge, accepted** (ADR-003) |
| Q4 | **Sync transport for v1** | A. Folder-based (user's own iCloud/Dropbox/Syncthing) · B. Self-hosted relay first · C. Hosted service first | **A then B.** Folder sync means zero infrastructure for desktop↔desktop; the relay is needed for phones without a shared folder and comes in the same milestone. No hosted service unless wanted later. | **A then B, accepted** |
| Q5 | **Platform priority** | Desktop first (M1–M3), phone in M4 · Phone capture earlier (swap M3/M4) | **Desktop first**, but confirm: if phone capture is the thing you'd use most on day one, swap M3 and M4. | **Desktop first, accepted** |
| Q6 | **Mobile scope at first release** | Capture + read + tasks + search (no full editor) · Full parity | **Capture + read + tasks + search.** Full editing on phone can follow once the editor is stable on desktop; it is the same web component. | **Capture + read + tasks + search, accepted** |
| Q7 | **Licence** | MIT · Apache-2.0 · AGPL-3.0 · Source-available / proprietary | **MIT or Apache-2.0** if the goal is adoption and contributions; **AGPL** if you want to prevent hosted forks. Affects library choices (e.g. tldraw has a licence with a watermark clause for commercial use). | **MIT for now** (ADR-004) |
| Q8 | **AI provider policy** | Local-only · Local default + opt-in API (Claude/OpenAI/etc.) · API-first | **Local default + opt-in API.** Keeps the privacy promise; API gives better answers when you choose. | **Local default + opt-in API, accepted** |
| Q9 | **Whiteboard engine** | tldraw · Excalidraw · custom canvas | **tldraw** (extensible shapes, strong editor model) subject to licence check under Q7; Excalidraw as fallback. | **tldraw, accepted** (licence check at M5) |
| Q10 | **Editor model** | Markdown source with live preview (CodeMirror 6) · Rich editor that saves Markdown (TipTap/ProseMirror) | **TipTap/ProseMirror saving Markdown**, with a raw-Markdown toggle. Better for embeds, tables and non-technical editing; Markdown stays the on-disk format either way. | **TipTap/ProseMirror saving Markdown, accepted** (ADR-005) |
| Q11 | **Monorepo layout** | Single repo (`core/`, `apps/`, `packages/`, `plugins/`) · Separate repos per app | **Single repo**; the whole point is one core shared by every shell. | **Single repo, accepted** |
| Q12 | **Large / binary assets in sync** | Sync everything · Size threshold, reference-only above it · Never sync assets, only metadata | **Size threshold** (default 500 MB, configurable), with cloned repos and downloaded video defaulting to reference-only on phones. | **Size threshold, accepted** |
| Q13 | **Name collision** | "Graphite" is also an existing open-source 2D graphics editor (graphite.rs) and a code-review tool (graphite.dev) | Keep the name for the repo; decide on a product name before public release (M8). Not blocking. | **Keep name, decide before release** |
| Q14 | **Anything to drop from the feature catalogue now?** | See the `Decision` columns in `01-features.md` | Nothing is required; P2 items are already positioned post-1.0 or as plugins. | **Nothing dropped** |
