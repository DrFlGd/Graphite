# Graphite

A multi-modal "second brain" for capturing ideas, projects and knowledge areas, organizing the material around them (text, images, video, 3D models, source code, web pages), connecting it all together, and turning it into finished projects.

Development has not started yet. The plan, feature set and milestones live in [`ROADMAP.md`](ROADMAP.md) and the [`docs/plan/`](docs/plan/) folder.
